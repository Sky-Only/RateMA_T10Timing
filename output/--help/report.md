# 20/120 日均线利率择时策略回测报告

## 1. 运行配置

- 数据源：`data\csv\panel.csv`
- 标的指数：`CBA04502.CS`（中债-10年期国债净价(总值)指数）
- 底层利率指标：`DR001`, `R001`, `DR007`, `R007`, `M0017139`
- 回测区间：2011-06-27 ~ 2026-09-16
- 均线：20 日 / 120 日简单移动平均
- 重合判定模式：`bp`，阈值 5
- 重合区间定义：绝对 5 bp（0.05 个百分点）
- 交易成本：单边 2bp（万分之2），双边合计 4bp；方向 long_short（价格口径：收盘价）
- 执行时滞：T 日信号，T+1 日收盘执行；空仓不计利息
- 年化系数：252 个交易日

## 2. 策略指标定义

| 条件 | 标记 | 含义 |
| --- | --- | --- |
| MA20 > MA120 | -1 | 短期资金成本高于中长期水平，流动性边际趋紧 → 债券空头 |
| MA20 < MA120 | +1 | 短期资金成本低于中长期水平，流动性相对宽松 → 债券多头 |
| \|MA20 - MA120\| ≤ 重合阈值 | 0 | 两线重合，延续上一交易日的有效信号 |

## 3. 评估窗口与起算口径

**评估起点定义为「首个有效信号日」**，即 `signal_eff` 首次非空的交易日（跳过 MA 未就绪的预热期）。策略与基准在同一日期、同一初始资金上归一，预热期不计入任何绩效指标。

以 `DR001` 为例：

| 项目 | 值 |
| --- | --- |
| 数据区间 | 2010-12-31 ~ 2026-09-16 |
| MA120 预热期 | 2010-12-31 ~ 2011-06-24（119 个交易日，信号为空，不计入） |
| **评估起点（首个有效信号日）** | **2011-06-27** |
| 评估终点 | 2026-09-16 |
| 评估交易日数 | 3808 |
| 首个有效信号 | -1（空头/空仓） |
| 首个建仓日 | 2011-08-26（信号日后第 44 个交易日；T+1 执行，且期间无 +1 信号） |
| 基准建仓 | 2011-06-27 @ 105.5945（含 0.0200% 建仓成本） |

> 注意：首个有效信号为 -1，因此评估起点当天及之后的一段时间策略保持空仓，直到 2011-08-26 才首次建仓。该空仓期正是信号本身的结论（空头区间不参与），基准同期满仓。

各指标的评估起点一致（均为 MA 预热结束后的首个有效信号日）；逐指标明细见 `evaluation_window.csv`。
